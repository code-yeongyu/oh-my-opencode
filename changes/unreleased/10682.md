**Contributors: package logs no longer conflict between pull requests.** An entry for `packages/<name>/changes.md` now goes in the pull request's own `changes/unreleased/<pr>.md` as a `<!-- changes-log: ... -->` block, after its changelog paragraph; a job writes the blocks into the logs and the release compiles any that are left. Branches that still edit a package log convert with `bun script/compile-package-logs.ts from-diff --base origin/dev --pr <n>`. ([#10682](https://github.com/code-yeongyu/oh-my-openagent/pull/10682))
